# Telegram 扫码功能实施计划

作者：Carinoasd

1. 新增短期登录请求表及版本标记，事务处理扫码、确认、拒绝、取消及兑换。账号安全字段变化时作废旧请求。
2. 增加默认关闭的配置与公开布尔能力；V2 接口复用现有意图头、凭据头、限流与登录服务；Bot 私聊要求明确确认。
3. 本地生成二维码；登录页加入扫码界面；设置、换绑及注册复用二维码组件，补齐三种语言。
4. PostgreSQL 测试并发、失效、重放及恢复；Firefox 验证响应布局、实际二维码和异步状态；运行全套检查。
